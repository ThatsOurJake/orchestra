# Introduction

Orchestra is a program that allows the creation of flows, mainly for chatting to Bot agents. The main idea is to allow the chaining of Bot agents together with each agent having their own responsibility. However you could also have 1 agent and have a simple conversation.

Orchestra isn't a magical tool and the actions to take off the back of a response is down to the developer of the flow.

This site uses Chromes inbuilt AI agent. Allowing this once the model has downloaded to work offline, on your machine with no external calls.

## Current Support

Orchestra right now supports only Chrome's inbuilt AI agent. You'll need to configure this as part of the [Getting Started](/docs/getting-started) steps to use Orchestra. 

## Repository

The Orchestra repository can be found at: [https://github.com/ThatsOurJake/orchestra](https://github.com/ThatsOurJake/orchestra). The repo contains an `examples` folder which contains flows that can be imported and tried out.
