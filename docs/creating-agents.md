# Creating Agents

Agent creation can be found under [Agents](/agents).

## Creating a New Agent

When creating an agent you will be asked to provide:

1. **Name** - The name of the agent
2. **Prompt** - This prompt will be provided as a system prompt to the agent upon initialization

## Importing Flows with Agents

When a flow is imported, if the agent does not exist then it will be created automatically with the prompt stored in the flow.

Learn more about flows in [Creating Flows](/docs/creating-flows).

## Managing Agents

Under [Agents](/agents) you are able to:

- **Edit prompts** - Modify the system prompt of any agent
- **Delete agents** - Remove any agents that aren't the default ones shipped with Orchestra

Note: You cannot delete the default agents (Business Analyst, Junior Developer, Junior Tester).
